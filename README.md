# 🛸 AGY Context HUD

> **Нативный компактный виджет мониторинга контекста для Google Antigravity IDE (Windows & macOS)**.  
> Автоматически магнитится к окну Antigravity, динамически отслеживает активный чат и предупреждает о приближении к зоне деградации внимания модели.

---

## ⚡ Особенности

- 🧲 **Магнитная привязка к окну (Win32 DWM / 28 FPS)**:
  Виджет примагничен к правому нижнему углу окна `Antigravity.exe`. При перемещении или изменении размера Antigravity виджет плавно перемещается вместе с ним. Автоматически скрывается при минимизации IDE.
- 🔄 **Авто-переключение активного чата**:
  Читает наносекундные таймстемпы `last_user_view_time` из метаданных Antigravity (`~/.gemini/antigravity/annotations/<conv_id>.pbtxt`). Мгновенно переключает статистику при клике на любой чат в боковой панели.
- 🎨 **Нативный дизайн в стиле Antigravity Carbon**:
  Палитра Google DeepMind / Antigravity (`#131314`, `#1e1f22`, `#2b2d31`, `#e3e3e3`) с мягкими акцентами Google Gemini.
- 📊 **Разбивка контекста по 4 категориям**:
  - `Прав` — Системные правила (`GEMINI.md`), промпт и скиллы.
  - `Чат` — Пользовательские сообщения и ответы агента.
  - `Тул` — Чтение файлов, вызовы тулов и вывод терминала.
  - `Мысл` — Внутренние рассуждения агента (`thinking`).
- 🚦 **Умный лимит внимания (Smart Limit 150k токенов)**:
  - 🟢 **Свежий контекст (`< 50%`)**: Максимальная фокусировка.
  - 🟡 **Нагрузка растёт (`50–82%`)**: Рекомендуется запланировать `/handoff`.
  - 🔴 **Зона деградации (`> 82%`)**: Высокий риск потери деталей и таймаутов стрима.
- 📋 **Кнопка быстрой передачи контекста (`⎘`)**:
  В один клик копирует команду сохранения сессии в буфер обмена для переезда в чистый чат.
- ➖ **Мини-режим (`—`)**:
  Сворачивание в ультра-компактную полоску `248 × 26 px`.

## 🚀 Запуск и Установка

### Требования
- Python 3.10+ (с включённым `tkinter`, который идёт в стандартной поставке Python для Windows).
- Google Antigravity IDE.

### Запуск
```cmd
run_hud.bat
```
Либо напрямую через Python:
```bash
pythonw hud_app.py
```

### Автозапуск с Windows
Создайте ярлык для `run_hud.bat` и поместите его в папку автозагрузки Windows (`Win + R` -> `shell:startup`).

---

## 🛠 Структура проекта

- `analyzer.py` — Движок анализа логов `transcript_full.jsonl`, калиброванный токенизатор и парсер аннотаций `pbtxt`.
- `hud_app.py` — Tkinter UI с Win32 DWM трекингом геометрии окна Antigravity.
- `run_hud.bat` — Тихий запуск через `Shell.Application` на интерактивном рабочем столе.
